# ⚡ Atharav Narang — Portfolio 3.0

Interactive personal developer portfolio featuring WebGL procedural animations, dual dark/light aesthetics, and an embedded AI assistant.

[✨ Live Demo](https://atharav001n.vercel.app) • [💼 LinkedIn](https://linkedin.com/in/atharav-narang-132b74273) • [🐙 GitHub](https://github.com/Atharav001)

---

## 🌟 Highlights

- **WebGL Cosmic Rays**: Procedural Three.js background rays with real-time cursor tracking and interactive color shifting.
- **Dual Themes**: Obsidian Dark mode with neon lime/coral accents and high-contrast Light mode with circular View Transitions.
- **Ask About Atharav AI**: Embedded retrieval-augmented assistant powered by Google Gemini and Supabase `pgvector`.
- **Fluid Motion**: Lenis smooth scrolling with Framer Motion scroll-linked spring animations and 3D perspective tilt cards.
- **Live Location Clock**: Real-time timezone status indicator (`Asia/Kolkata`).

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Three.js, Framer Motion, Lenis, Lucide Icons, Vanilla CSS Tokens
- **Backend & AI**: Vercel Serverless Functions, Google Gemini API, Supabase `pgvector`
- **Credits**: Thinking Orb component by [Jakub Antalík](https://github.com/jakubantalik/thinking-orbs)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Atharav001/portfolio-3.0.git
cd portfolio-3.0

# Install dependencies
npm install

# Run local development server
npm run dev
```
